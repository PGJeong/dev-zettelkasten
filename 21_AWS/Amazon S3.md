- **내구성** - Amazon S3는 객체의 복사본을 만들어 단일 AWS 리전 내의 여러 가용 영역(AZ)에 저장함으로써 타의 추종을 불허하는 내구성을 유지(99.999999999% 11 9s의 내구성)

- **접두사 및 태그** - 모든 객체는 접두사라는 공유 이름으로 구성될 수 있으며, 키-값 쌍을 가진 태그를 각 객체에 추가하여 데이터를 추적하고 구성할 수 있음 (각 객체에 최대 10개의 태그)

- **수명 주기 관리** - **S3 Intelligent-Tiering**을 이용하여 데이터 및 액세스 패턴을 모니터링한 다음 자동으로 적절한 스토리지 클래스로 변경할 수 있으며, **수명 주기 구성 규칙**을 사용해 스토리지 클래스를 변경할 수 있음

- **Amazon S3 Analytics** - **스토리지 클래스 분석**을 이용해 데이터 액세스 패턴을 관찰한 후, 분석 결과를 이용해 수명 주기 정책을 개선하거나 적절한 스토리지 클래스로 전환할 수 있음

- Amazon S3(Simple Storage Service)는 여러 사용 사례에 최적화된 6가지 스토리지 클레스를 제공
  ![[../80_Assets/Pasted image 20260731025237.png]]

- **버전 관리 (Versioning)** - 동일한 키(파일명)로 객체를 업로드하거나 삭제할 때, 기존 파일에 버전 ID를 부여하여 이전 상태들을 모두 보관하는 기능
	- 실수로 객체를 덮어쓰거나 삭제하는 것을 방지 및 과거 버전으로 복원할 수 있음
	- 중요 객체의 영구 삭제 및 버전 관리 상태 변경 시 MFA(2차 인증)를 하도록 설정 가능

- **교차 리전 복제 (CRR)** - 원본 버킷에 생성/수정되는 객체를 다른 AWS 리전에 있는 대상 버킷으로 비동기(Asynchronous) 자동 복제하는 기능
	- 재해 복구(DR), 지리적으로 가까운 리전에서 읽기 성능 향상 등 가능
	- 원본(Source) 버킷과 대상(Destination) 버킷 둘 다 **버전 관리가 활성화**되어 있어야 함
	- 원본 버킷에서 객체를 읽어 대상 버킷으로 복사할 수 있는 IAM 역할 지정 필요

# S3 Standard
액세스 빈도가 높은 데이터를 위한 스토리지 클래스

![[../80_Assets/Pasted image 20260731020521.png]]

- S3의 기본 스토리지 클래스이며 다른 스토리지 클래스를 선택하지 않으면 자동으로 할당
- 성능에 민감한 사용 사례, 밀리초 액세스 시간을 필요로 하는 사례 및 가장 자주 액세스되는 데이터를 위해 설계

- **최소 기간 및 최소 크기** - 최소 및 최대 스토리지 기간이 없으며, 최소 크기 요구 사항이 없음
- **검색 시간** - 즉시 객체를 검색할 수 있음

# S3 Standard-Infrequent Access (S3 Standard-IA)
액세스 빈도가 낮은 데이터를 위한 스토리지 클래스

![[../80_Assets/Pasted image 20260731020915.png]]

- 액세스 빈도가 낮지만 필요할 때 빠르게 액세스해야 하는 데이터를 위한 스토리지 클래스
- S3 Standard–IA는 S3 Standard의 뛰어난 내구성, 높은 처리량 및 짧은 지연 시간을 저렴한 GB당 스토리지 요금과 GB당 검색 요금으로 제공

- **최소 기간 및 최소 크기** - 최소 30일 동안 저장할 128KB 이상의 객체에 사용
	- 객체가 128KB 미만이더라도 128KB에 대한 요금을 부과
	- 최소 스토리지 기간인 30일이 끝나기 전에 객체를 삭제하면 30일 요금이 부과
- **검색 시간** - 즉시 객체를 검색할 수 있음

---
# S3 One Zone-Infrequent Access (S3 One Zone-IA)
액세스 빈도가 낮은 데이터를 위한 스토리지 클래스 (단일 가용 영역)

![[../80_Assets/Pasted image 20260731021348.png]]

- 객체 데이터를 하나의 가용 영역에만 저장 (재해에 의한 가용 영역의 물리적 손실에 취약)
- 자주 액세스하지 않는 데이터에 대한 저렴한 옵션을 원하지만 S3 Standard 또는 S3 Standard-IA 스토리지와 같은 가용성 및 복원력이 필요 없는 고객에게 적합
- S3 Standard와 동일한 높은 내구성, 많은 처리량 및 짧은 지연 시간을 저렴한 GB당 스토리지 요금과 GB당 검색 요금으로 제공

- **최소 기간 및 최소 크기** - 최소 30일 동안 저장할 128KB 이상의 객체에 사용
- **검색 시간** - 즉시 객체를 검색할 수 있음

# S3 Glacier
객체 아카이빙을 위한 스토리지 클래스

![[../80_Assets/Pasted image 20260731023013.png]]

- 데이터 보관을 위한 안전하고 내구력 있으며 저렴한 스토리지 클래스

- **최소 기간 및 최소 크기** - 최소 90일 동안 저장할 40KB 이상의 객체에 사용
	- 90일 이전에 삭제하는 객체에 대해서는 남은 기간의 스토리지 비용에 해당하는 비례 할당으로 계산된 요금이 부과
	- 크기가 40KB보다 작은 객체는 저장될 수는 있지만, 40KB에 해당하는 요금이 부과
- **검색 시간** - 세 가지 검색 옵션을 제공: `신속(1~5분)` / `표준(3~5시간)` / `대량(12시간)`

# S3 Glacier Deep Archive
객체 장기 아카이빙을 위한 스토리지 클래스

![[../80_Assets/Pasted image 20260731023529.png]]

- S3에서 가장 저렴한 비용의 스토리지 클래스이며 1년에 한두 번 정도 액세스할 수 있는 데이터의 장기 보관(7-10년) 및 디지털 보존에 적합
- 저장된 모든 객체는 지리적으로 분산된 3개 이상의 가용 영역에 복제 및 저장되며, 99.999999999%의 내구성으로 보호되며 기본 검색 시간은 12시간

- **최소 기간 및 최소 크기** - 최소 180일 동안 저장할 40KB 이상의 객체에 사용
	- 180일 이전에 삭제하는 객체에 대해서는 남은 기간의 스토리지 비용에 해당하는 비례 할당으로 계산된 요금이 부과
	- 크기가 40KB보다 작은 객체는 저장될 수는 있지만, 40KB에 해당하는 요금이 부과
- **검색 시간** - 2가지 검색 옵션을 제공: `표준(12시간 이내)` / `대량(48시간 이내)`

# S3 Intelligent-Tiering
알 수 없거나 변화하는 액세스를 위한 스토리지 클래스

![[../80_Assets/Pasted image 20260731022129.png]]

- 운영 오버헤드 없이 비용 효과적인 액세스 계층으로 데이터를 자동으로 이동하여 비용을 최적화하기 위해 설계된 S3 스토리지 클래스
- Amazon S3 Inventory를 사용하여 S3 Intelligent Tiering 스토리지 클래스에 저장된 객체의 액세스 계층을 확인할 수 있음
- 객체가 아카이브되기 전까지 시간을 연장할 수 있음

- **최소 기간 및 최소 크기** - 최소 30일 동안 저장할 객체에 사용, 최소 객체 크기는 없으나 128KB보다 작은 객체는 적합하지 않으며 항상 빈번한 액세스 계층 요금으로 저장됨
- **검색 시간** - 객체 검색 시간은 계층에 따라 다름

# Amazon S3 요금

- 최소 수수료 없이 사용한 만큼만 지불하면 됨
- 네 가지 비용 요소를 고려하여 스토리지 클래스를 결정
	- **스토리지** - S3 버킷에 객체를 저장하는 비용
	- **요청 및 검색** - S3 버킷 및 객체를 대상으로 수행한 요청에 대한 요금
	- **데이터 전송** - S3로 들어오고 나가는 모든 대역폭에 대한 요금
	  (인터넷에서 전송, 동일 AWS 리전 내 인스턴스로 전송, CloudFront로 전송된 경우 제외)
	- **관리 및 복제** - 스토리지 관리 기능(S3 인벤토리, 분석 및 객체 태킹)에 대한 요금
